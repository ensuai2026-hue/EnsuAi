# ENSU.AI — Produk DNA Founder

Platform AI Jenama Malaysia #1. Inject DNA founder anda ke dalam produk OEM yang ikonik — skincare, supplement & lebih lagi.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in `.env` to your Gemini API key
3. Run the app:
   `npm run dev`
4. Build for production:
   `npm run build`
